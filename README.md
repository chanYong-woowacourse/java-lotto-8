# java-lotto-precourse
- 콘솔 기반 로또 발매기 프로그램
- 사용자가 구매 금액과 로또 번호를 입력
- 당첨 번호와 보너스 번호도 입력
- 결과와 수익률을 출력
- 잘못된 입력 시 `[ERROR]` 메시지 후 재입력

## 주요 기능
1. **금액 입력**
   - 사용자가 구매할 금액 입력
   - 1000원 단위가 아닌 경우, 음수 또는 비정수 입력 처리

2. **로또 발행**
   - 구매 금액에 맞춰 사용자가 직접 번호를 입력
   - 번호 개수 및 범위 검증

3. **당첨 번호 및 보너스 번호 입력**
   - 당첨 번호 6개와 보너스 번호 1개 입력
   - 번호 중복 및 범위 검증

4. **당첨 조건 관리 및 결과 계산**
   - 1~5등 판정 및 당첨 개수 집계
   - 총 상금 계산 및 수익률 계산

5. **게임 흐름 및 입출력**
   - 게임 전체 흐름 제어(금액 입력 → 로또 번호 입력 → 당첨 번호 입력 → 결과 출력)
   - 잘못된 입력 시 재입력 처리

## 예외 상황
- 금액 입력이 정수형이 아니거나 1000원 단위가 아닐 경우
- 로또 번호 개수 불일치 또는 범위 벗어남
- 보너스 번호가 당첨 번호와 중복
- 기타 내부 상태 이상 발생 시

## 개발 방식
- **TDD(Test-Driven Development)** 방식 적용
